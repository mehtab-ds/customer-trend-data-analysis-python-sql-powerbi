# 🛍️ Customer Shopping Behavior Analysis  

Uncovering insights from **3,900 purchases** using Python, SQL, and Power BI to drive strategic business decisions.  

---

## 📌 Project Overview  
This project demonstrates a complete workflow for analyzing customer shopping behavior:  
- **Data Cleaning** with Python notebooks  
- **Data Analysis** using SQL queries  
- **Visualization & Reporting** with Power BI dashboards  

The goal is to transform raw transactional data into actionable insights for business strategy.  

---

## 🔧 Tech Stack  
- **Python (Pandas, NumPy, Jupyter Notebook)** → Data cleaning & preprocessing  
- **SQL** → Querying, aggregations, and analysis  
- **Power BI** → Interactive dashboards & storytelling  

---

## ⚙️ Workflow  
- **Data Cleaning (Python Notebook):** handled missing values, standardized formats, and prepared structured datasets  
- **Data Analysis (SQL):** revenue breakdowns, product performance, shipping preferences, subscription impact, and customer segmentation  
- **Dashboard (Power BI):** interactive reporting highlighting revenue drivers, product trends, and customer behavior  

---

## 📊 Key Insights  
- **Male customers** generated higher revenue ($157,890), but **female customers** showed strong purchasing power ($75,191)  
- **Young adults** contributed the highest revenue ($62,143)  
- **Gloves, Sandals, Boots** were top‑rated products; **Blouse, Pants, Jewelry** were best sellers  
- **Express shipping** customers spent more ($60.48 vs $58.46)  
- **Subscribers (27%)** showed stronger engagement compared to non‑subscribers
